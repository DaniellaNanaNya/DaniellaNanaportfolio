Installation de MariaDB sur Debian

Procédure prévisionnelle — elle sera mise à jour avec mes captures d'écran une fois l'installation réalisée sur mon PC Debian.
SystèmeDebian 12 / 13
LogicielMariaDB Server
Droitssudo / root
Durée~ 15 min

Objectif

Installer un serveur de bases de données MariaDB sur ma machine Debian, le sécuriser, puis créer une base et un utilisateur dédié pour pratiquer le SQL.

  1. Mettre à jour le système

    Avant toute installation, on met à jour la liste des paquets et les paquets déjà installés.

    sudo apt update && sudo apt upgrade -y
    Capture d'écran à ajouter

  2. Installer MariaDB

    MariaDB est disponible directement dans les dépôts officiels de Debian.

    sudo apt install mariadb-server mariadb-client -y
    Capture d'écran à ajouter

  3. Vérifier que le service tourne

    On contrôle que le service est actif et on l'active au démarrage de la machine.

    sudo systemctl status mariadb
sudo systemctl enable mariadb
mariadb --version

    La ligne Active: active (running) en vert confirme que le serveur fonctionne. Touche q pour quitter l'affichage.

    Capture d'écran à ajouter

  4. Sécuriser l'installation

    Un script fourni avec MariaDB permet de supprimer les réglages par défaut peu sûrs.

    sudo mariadb-secure-installation
    Question poséeRéponse
    Enter current password for rootEntrée (vide)
    Switch to unix_socket authenticationn
    Change the root password?Y (choisir un mot de passe fort)
    Remove anonymous users?Y
    Disallow root login remotely?Y
    Remove test database?Y
    Reload privilege tables now?Y
    Capture d'écran à ajouter

  5. Se connecter à MariaDB

    On ouvre la console SQL en tant qu'administrateur.

    sudo mariadb

    L'invite devient MariaDB [(none)]> : on peut maintenant taper des requêtes SQL.

  6. Créer une base et un utilisateur

    On évite de travailler avec root : on crée une base de test et un utilisateur qui n'a des droits que sur elle.

    CREATE DATABASE portfolio;
CREATE USER 'daniella'@'localhost' IDENTIFIED BY 'MotDePasseFort!';
GRANT ALL PRIVILEGES ON portfolio.* TO 'daniella'@'localhost';
FLUSH PRIVILEGES;
EXIT;
    Capture d'écran à ajouter

  7. Tester avec quelques requêtes SQL

    On se reconnecte avec le nouvel utilisateur et on crée une première table.

    mariadb -u daniella -p

USE portfolio;
CREATE TABLE competences (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nom VARCHAR(50) NOT NULL,
  niveau INT
);
INSERT INTO competences (nom, niveau) VALUES ('SQL', 45), ('Linux', 75);
SELECT * FROM competences;
